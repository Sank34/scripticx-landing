<h2 id="starea-api-ului">Starea API-ului</h2>

ScripticX nu oferă momentan un API public stabil. Proiectăm experiența pentru
dezvoltatori înainte de a publica chei, endpoint-uri sau reguli de versionare.

Documentația rămâne în site-ul principal pentru a folosi aceeași navigare,
căutare și identitate vizuală.

<h2 id="principii-de-design">Principii de design</h2>

Viitorul API va urmări:

- URL-uri previzibile, orientate pe resurse;
- contracte versionate și schimbări documentate;
- credențiale cu permisiuni limitate;
- răspunsuri clare pentru erori și rate limits;
- exemple pentru cURL, JavaScript și Python.

<h2 id="resurse-planificate">Resurse planificate</h2>

| Resursă | Utilizare posibilă |
| --- | --- |
| Profil | Afișarea profilului public al unui cursant |
| Probleme | Listarea provocărilor publice |
| Soluții | Istoricul propriilor trimiteri |
| Clase | Integrarea fluxurilor educaționale |

Autentificarea, datele private ale claselor și execuția codului necesită o
analiză suplimentară de securitate.

<h2 id="actualizari">Actualizări</h2>

Până atunci, nu construi integrări folosind endpoint-uri interne nedocumentate.
