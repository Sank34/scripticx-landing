<h2 id="ce-este-scripticx">Ce este ScripticX?</h2>

ScripticX este o platformă de învățare a programării prin probleme clare,
execuție instant și feedback din comunitate. Primii pași sunt accesibili, fără
să ascundem logica de care vei avea nevoie mai târziu.

Platforma combină:

- exerciții interactive de programare;
- un editor și un mediu de execuție în browser;
- clase și teme;
- urmărirea progresului;
- distribuirea soluțiilor și funcții de comunitate.

<h2 id="prima-ta-sesiune">Prima ta sesiune</h2>

1. Creează un cont sau autentifică-te pe [platforma ScripticX](https://platform.scripticx.org).
2. Deschide **Probleme** și alege un exercițiu introductiv.
3. Citește cu atenție datele de intrare și rezultatul așteptat.
4. Scrie soluția în editor.
5. Apasă **Rulează**, verifică rezultatul și trimite soluția când ești pregătit.

Activitatea este asociată contului tău, astfel încât să poți reveni și să-ți
urmărești progresul.

<h2 id="cum-functioneaza-invatarea">Cum funcționează învățarea</h2>

ScripticX încurajează cicluri scurte de feedback: înțelegi problema, scrii o
soluție mică, o rulezi și o îmbunătățești.

| Zonă | Cum te ajută |
| --- | --- |
| Probleme | Exersezi câte un concept |
| Editor | Scrii și rulezi cod în browser |
| Clase | Urmezi teme structurate |
| Comunitate | Compari abordări și distribui soluții |
| Dashboard | Urmărești activitatea și progresul |

<h2 id="pasii-urmatori">Pașii următori</h2>

bucle și input. Poți deschide și
[editorul online](https://platform.scripticx.org/editor) pentru a experimenta.
